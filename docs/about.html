VO-DAW / StateVO

Record the voice. Build the world around it after.

A voice-over DAW that runs in a browser tab — multi-take recording, a non-destructive timeline, a fixed voice chain, and LUFS-accurate export presets. Foley search is built in: find a door slam, drag the card onto the timeline, keep going.

Open StateVO → Source on GitHub

What it does

Everything that isn't spoken word has been left out on purpose. No MIDI, no instruments, no piano roll, no routing matrix.

Record

Big red button, one voice track, multi-take. Record over the same spot again and the takes stack — flick between them with ◀ ▶ without losing any of them. A time selection turns Record into a punch-in.

Edit

Non-destructive: split, trim from either edge, drag fade handles, move clips between lanes, ripple-delete a fluffed line across every track at once. Nothing ever overwrites recorded audio.

Foley, built in

Search Freesound's Creative Commons library from the left panel, preview inline, then drag the card onto a lane. Landing on a lane joins that track; dropping below the last one makes a new track.

Voice chain

Cleanup → de-ess → compress → EQ → limit, fixed and in that order, with one-click Social / Podcast / Raw presets. The same graph runs for monitoring and for the export render, so what you heard is what ships.

Script & markers

Import a .txt or .md script, pull section markers out of the headings, and read from a teleprompter that scrolls with playback.

Export

Reels / TikTok at −14 LUFS, Podcast at −16, or a clean WAV. Normalisation happens before the limiter, then it re-measures and hands you a loudness report next to the file.

Getting going

Recording and editing work the moment you open the page. The SFX search needs one five-minute setup, because Freesound's API refuses direct browser calls.

  1. Open the app and hit Arm, then Record. Your browser will ask for the microphone once. Projects and takes live in that browser's own storage — nothing is uploaded anywhere.
  2. Get a free Freesound API key at freesound.org/apiv2/apply.
  3. Deploy the proxy Worker — forty lines, Cloudflare free tier. It holds the API key server-side so it never reaches the page.
  4. Paste the Worker URL into the ⚙ settings in the SFX panel and hit Test connection. Search works from then on, on any machine you open the app on.

Where things stand

Record → edit → export Working end to end. Export loudness verified against pyloudnorm — a −14 LUFS Reels export measures −14.1.
Multi-track timeline Lanes, waveforms, mute/solo/collapse, drag-and-drop from the SFX panel and from the desktop.
SFX search Built into the app. Needs the Worker deployed once.
Take comping Take stacks and ◀ ▶ switching work. Picking the best sentence across takes still means splitting by hand.
Desktop build The PySide6 app is still in the repo under statevo/ — better latency, real device control, no browser limits. The browser build is the one you can open anywhere.
